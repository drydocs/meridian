# Self-Repaying Loan Strategy Guide

This guide explains the self-repaying loan strategy implemented in `@meridian/strategies`. It covers the core financial mechanism, configuration parameters, risk factors, mitigation mechanics, and instructions for running simulation backtests.

## Simulation-Only Boundary Notice

This strategy engine operates strictly within a simulation and backtest harness. The engine does not sign transactions, does not submit transactions to live networks, and has no integration with live mainnet vaults or real user funds. All operations described herein pertain exclusively to offline models, historical feeds, and backtest scenarios.

## 1. Core Mechanism

A self-repaying loan allows a borrower to deposit collateral, draw a debt position up to a defined Loan-to-Value (LTV) limit, and allocate the borrowed principal into an interest-generating yield source. Over time, yield accruals automatically amortize the outstanding debt without requiring out-of-pocket cash repayments.

The lifecycle comprises three primary phases:

1. **Open**: The borrower supplies collateral (for example, XLM) into the protocol. Based on the collateral value and the configured `openingLoanToValue`, debt units (for example, USDC) are borrowed. The strategy immediately routes the borrowed principal into the selected yield vehicle.
2. **Amortize**: At each simulation tick, the yield accrued by the deployed principal is harvested. These yield proceeds are converted and applied directly to reduce the outstanding debt balance. Borrow interest also accrues during this period.
3. **Close**: When the accumulated yield has fully paid off the debt, or when the borrower manually unwinds the position, the yield position is redeemed, residual balances are settled, and the original collateral is released back to the borrower.

## 2. Configuration Options & Safe Ranges

The strategy is parameterized via `SelfRepayingLoanConfig`. The available parameters, valid boundaries, and recommended safe operating ranges are listed below:

| Parameter | Type | Validation Bounds | Safe Range | Description |
| :--- | :--- | :--- | :--- | :--- |
| `collateralAsset` | `string` | Non-empty asset symbol | e.g. "XLM" | Asset deposited as loan collateral. |
| `borrowAsset` | `string` | Non-empty asset symbol | e.g. "USDC" | Asset borrowed against collateral. |
| `yieldSource` | `string` | Non-empty identifier | e.g. "blend_usdc_pool" | Target yield adapter for borrowed funds. |
| `openingLoanToValue` | `Decimal` | `0 < LTV < liquidationThreshold` | `0.30 - 0.50` (30% to 50%) | Target initial borrowing ratio relative to collateral value. |
| `liquidationThreshold` | `Decimal` | `openingLoanToValue < threshold <= 1.0` | `0.75 - 0.85` (75% to 85%) | LTV ratio at which position becomes liquidatable. |
| `liquidationPenalty` | `Decimal` | `0 <= penalty <= 0.50` | `0.05 - 0.10` (5% to 10%) | Surcharge deducted if liquidation is triggered. |
| `rateMode` | `string` | `"fixed"` or `"variable"` | Context dependent | Interest calculation method applied across periods. |
| `autoDeleverageThreshold` | `Decimal` | `openingLoanToValue < auto < liquidationThreshold` | `0.65 - 0.70` (65% to 70%) | LTV trigger to initiate preemptive debt paydown. |

### Rate Modes

- **Fixed Rate**: Borrow interest and yield accruals use deterministic periodic percentages. Useful for baseline viability modeling.
- **Variable Rate**: Borrow interest and yield yields fluctuate dynamically based on pool utilization curves and market scenarios.

## 3. Risks & Automated Mitigations

While the strategy automates repayment, market volatility introduces specific financial risks:

### Risk 1: Yield Collapse or Inversion
If the yield generated by the deployed capital drops below the borrow interest rate (a negative interest spread), the outstanding debt balance will expand rather than contract.
- **Mitigation**: The strategy monitors net spread across simulation intervals. If spread remains negative across consecutive checks, the strategy halts further borrowing and recommends position unwind.

### Risk 2: Collateral Drawdown
If the market price of the collateral asset declines rapidly, the position LTV increases toward the `liquidationThreshold`.
- **Mitigation**: The `autoDeleverageThreshold` triggers an automated emergency rebalancing step before liquidation can occur. A portion of the deployed yield principal is recalled to pay down debt, restoring the LTV to safe operating levels.

### Risk 3: Liquidation Penalty
If collateral drops faster than deleveraging can execute, third-party liquidators may seize collateral at a discount defined by `liquidationPenalty`.
- **Mitigation**: Conservative `openingLoanToValue` configurations (below 50%) provide substantial safety margin against market swings.

## 4. Running a Backtest Simulation

The backtest framework simulates strategy execution against synthetic or historical price data.

### Step 1: Install Dependencies
```bash
pnpm install
```

### Step 2: Run Strategy Tests and Golden Scenario
```bash
pnpm --filter @meridian/strategies test
```

### Step 3: Execute Custom Scenario
You can run scenario evaluations programmatically using the `SelfRepayingLoanStrategy` class:

```ts
import { Decimal, SelfRepayingLoanStrategy } from "@meridian/strategies";

const strategy = new SelfRepayingLoanStrategy({
  collateralAsset: "XLM",
  borrowAsset: "USDC",
  yieldSource: "blend_pool",
  openingLoanToValue: "0.40",
  liquidationThreshold: "0.80",
  liquidationPenalty: "0.08",
});

// 1. Open position with 1,000 XLM at $0.12 price
const openResult = strategy.open({
  collateralAmount: Decimal.fromString("1000.00"),
  collateralPrice: Decimal.fromString("0.12"),
});

console.log("Orders generated:", openResult.orders);
```

### Step 4: Interpreting the Run Report

The scenario runner produces a state report detailing:
- `debtAmount`: The remaining debt balance. A successful loan terminates with `debtAmount = 0`.
- `totalYieldAmortized`: The cumulative amount of debt paid off strictly through generated yield.
- `totalInterestAccrued`: Total borrowing fees accrued throughout the loan tenure.
- `currentLtv`: Real-time loan-to-value ratio across each interval tick.
